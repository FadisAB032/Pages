# 數獨日常 · Sudoku Studio

純 HTML、CSS、JavaScript 的繁體中文數獨網頁。沒有框架、外部套件、CDN、後端或建置流程，直接由 GitHub Pages 提供靜態檔案。

## 遊玩

選擇格子後，點擊下方 1～9 填答。題目給定數字無法修改；同行、同列、同宮與相同數字會高亮。數字在棋盤出現 9 次後，數字按鈕停用；清除後恢復，筆記不計入。

- 易／中／難／專家分別給定 35／28／24／22 個數字。專家提供更少的起始線索，適合想要更高挑戰的玩家。難度按線索數量區分，尚未採用解題技巧評級；同難度題目的實際推理難度可能不同。
- 每次開局以隨機回溯產生完整答案，再逐一移除線索；僅在仍有唯一解時接受移除。
- 專家若 30 次隨機生成仍無法達到 22 個線索，改用 6 張本地生成、已驗證唯一解的題目作為備援，再隨機重編數字、交換宮帶及宮內行列、轉置棋盤。這些變換保留唯一解與線索數，確保專家開局不會因低線索生成失敗；備援變體可能具有相同的邏輯結構。
- 筆記模式可切換候選數字；正確填答會清除相關格子的同數字筆記。
- 支援清除、最近 100 步復原、每局 3 次提示、錯誤顯示、暫停、完成畫面。
- 錯誤與提示次數為整局累計，復原不退還提示或錯誤次數。
- 用 localStorage 儲存當前局，重新整理可接續；分頁隱藏、暫停及對話框開啟時不計時。停用儲存或無痕模式可能無法保留進度。
- 支援手機、鍵盤操作、螢幕閱讀器標籤與減少動態效果設定。

## 鍵盤

| 按鍵 | 操作 |
| --- | --- |
| 方向鍵 | 移動選格 |
| 1～9 | 填答或切換筆記 |
| Delete / Backspace / 0 | 清除 |
| N | 切換筆記模式 |
| Ctrl / ⌘ + Z | 復原 |
| Space | 選格時暫停／繼續（其他按鈕保留原生空白鍵操作） |

## 檔案

- `index.html`：介面、遊戲區、規則及對話框。
- `style.css`：響應式暖白／墨綠設計。
- `engine.js`：解題、唯一解生成與輸入規則，亦可由 Node.js 匯入測試。
- `app.js`：DOM 操作、計時、自動儲存與遊戲流程。
- `tests/engine.test.cjs`：唯一解、難度、數字上限、鎖定題目、筆記與完成檢查。

## 執行與部署

直接開啟 `index.html`，或以任意靜態伺服器提供 `Sudoku/` 目錄。頁面使用相對路徑，可部署在任何子目錄。

本專案位於 `FadisAB032/Pages` 的 `Sudoku/`；沿用既有 GitHub Pages 的 `main` 分支發布流程，不需要新增工作流程或更改其他頁面。

```sh
node Sudoku/tests/engine.test.cjs
```

## UI 設計

桌面以棋盤與操作區為左欄，右欄呈現專注主題與玩法；手機收斂為單欄棋盤。選格、相關格、同數字分別使用三種綠色色階；輸入錯誤以紅色及狀態文字回饋。下方數字鍵同時顯示剩餘可填格數，填满以勾號標示。
