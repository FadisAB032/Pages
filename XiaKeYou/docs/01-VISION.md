# 01 — 產品願景與範圍

## 一句話

**一款讓玩家在充滿機會與後果的奇幻世界中，自行選擇怎麼生活的繁體中文瀏覽器 RPG。**

## 核心受眾

- 喜歡早期自由冒險 RPG、但不想受長篇線性劇情限制的玩家。
- 習慣桌面瀏覽器與短時段遊玩的玩家；支援手機觸控，但優先做好桌面操作。
- 喜歡探索、任務、收集、角色成長、敘事事件與自訂目標的人。

## 玩家體驗承諾

- **一開始就能自主行動**：進入城鎮後，三分鐘內可接下第一份委託。
- **每次開局都不同**：相同規則下，世界種子會影響路線、資源與任務組合。
- **選擇形成後果**：NPC 態度與地區聲望至少在 MVP 有基本可觀察變化。
- **進度安全**：關閉／重新整理網頁後可在同一裝置恢復冒險。
- **不以帳號為遊戲前提**：核心單人遊戲先離線可玩。

## 設計支柱

| 支柱 | 必須做的事 | 刻意避免 |
| --- | --- | --- |
| 自由冒險 | 任務、探索、成長是平行選擇 | 強制主線鎖功能 |
| 湧現故事 | 任務模板 × 地點 × NPC × 世界狀態 | 每個事件都手寫一次 |
| 世界有回應 | NPC 關係、聲望與時鐘影響結果 | 只有文字描述、無機制效果 |
| 養成與生命 | 行為導向的能力成長 | 只靠擊殺換等級 |
| 技術可持續 | 種子可重現、資料可測、存檔可遷移 | UI 與模擬緊耦合 |

## 最小可行版本（MVP）

### 必須有（P0）

1. 建立角色／選初始傾向；世界種子可由玩家設定或隨機生成。
2. 一座城鎮、一片野外、一座小型遺跡；可以在場景間往返。
3. 場景碰撞、移動、簡易互動、NPC 對話與酒館／委託板。
4. 四種委託：討伐、採集、送貨、探索。
5. 簡易即時戰鬥、生命值、消耗品、物品欄與裝備。
6. 至少三項能力的使用式成長與可理解的數值回饋。
7. 遊戲內日夜／時間推進、至少一個 NPC 與聲望反應。
8. 自動與手動存檔、繼續遊戲；儲存檔版本和基本遷移測試。
9. 繁體中文 UI、桌面鍵盤操作及基本觸控操作。

### 下一階段（P1）

- NPC 作息、好感與簡單隊友、更多區域及分支事件。
- 陣營聲望、善惡選擇、技能與裝備合成。
- 種子驅動的地下城地形與更多任務條件。
- 存檔匯入／匯出與內容擴充工具。

### 後續（P2/P3）

- 雲端存檔、帳號、跨裝置同步。
- 共同行動的同伴、結婚、家庭與後代傳承。
- 玩家自製委託及內容審核。
- 協作／多人世界與伺服器權威同步。

## 不做的事（MVP）

- MMO、PvP、多人即時同步。
- 具有大量生存數值的複雜經濟模擬。
- 結婚、生育或完整生命週期。
- AI 即時生成所有對話／無限制代理行為。
- 從原作直接取用任何美術、音樂、文本或資料庫。

## 成功標準

1. 新玩家不看指南，能完成「接任務 → 完成 → 回報」一次閉環。
2. 相同 seed + 相同玩家操作，在同版本規則下產生相同世界／任務關鍵結果。
3. 存檔與重載後，角色位置、背包、任務、世界時間與重要 NPC 狀態一致。
4. 兩種不同策略（戰鬥、探索／採集）都有持續成長回饋。
5. 靜態託管即可完成單人流程；API 故障不妨礙離線單人遊戲。

## 對外發行的 IP 原則
