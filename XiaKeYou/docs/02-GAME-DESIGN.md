# 02 — 遊戲設計規格（GDD v0.1）

## 1. 世界與視角

- 2D 俯視角、以 32×32 或 48×48 像素作為 tile 基準；先以可替換的自製幾何或開源授權素材驗證機制。
- MVP 區域包含：**邊境城鎮**（接任務、商人、休息）、**荒野**（敵人、素材）、**廢棄遺跡**（探索目標）。
- 每次新冒險產生 worldSeed。以偽亂數產生地點間連線、野外物件、採集位置、敵人與任務變化。
- 世界應同時有固定的「可理解結構」及可變的「冒險細節」，避免完全隨機導致任務不可解。
- 可進入區域必須連通；採集／交付／擊殺目標的生成結果必須通過有效性檢查。

## 2. 角色

### 初期數值

| 屬性 | 效果 | 典型成長方式 |
| --- | --- | --- |
| 體魄 | 最大生命、近戰承受能力 | 承受與完成戰鬥訓練 |
| 身手 | 移動速度、閃避／攻擊間隔 | 移動與武器練習 |
| 精神 | 法術／特殊能力的資源基礎 | 使用技能及探索事件 |
| 社交（後續） | 委託價格、NPC 友好門檻 | 對話、交易、回報任務 |

MVP 至少落地前三項。角色有 HP、耐力（若無玩法用途則延期）、金錢、背包與裝備槽；暫不設傳統角色等級的強制門檻。

### 行為式成長

- 針對可驗證的有效行動累積熟練度，而不是每個 frame 移動都加經驗值。
- 同一類行為存在冷卻與遞減，防止玩家原地連點刷能力。
- 升級訊息應顯示「哪個行為提升了哪項能力」。

## 3. 冒險流程

1. 在城鎮酒館選擇一份適合當前能力與世界狀態的委託。
2. 前往目標區域，在野外探索、戰鬥或採集。
3. 累積任務進度；必要時返回城鎮補給。
4. 向委託者交付成果，獲得金錢、物品或區域聲望。
5. 整理背包、強化角色、承接新的委託，或選擇自由探索。

## 4. 動態任務

### 任務模板（MVP）

| 類型 | 生成輸入 | 完成條件 | 失敗／取消 |
| --- | --- | --- | --- |
| 討伐 | 怪物類型、區域、數量 | 有效擊敗指定目標 | 可取消；後續可加入期限 |
| 採集 | 資源、數量、採集區 | 提交指定數量的可用物品 | 採集點需可達 |
| 送貨 | 發件人、收件人、包裹 | 找到收件 NPC 並完成交付 | 保護唯一包裹、處理遺失 |
| 探索 | 地點、事件標記 | 到達指定標記並完成互動 | 標記與地圖生成必須一致 |

任務實例包含 questId、templateId、seed、issuerNpcId、targetRegionId、objective、reward、status、deadline（選填）。
同類任務不得產生唯一目標不存在或交付對象無法接觸的狀況。任務不應依賴瀏覽器刷新後不再保留的臨時物件 ID。

### 任務生成流程

1. 從世界狀態與角色能力過濾適用模板。
2. 選擇當前已開放且可達的目標區域。
3. 以 seed 派生 deterministic 任務參數。
4. 驗證目標、獎勵、期限、NPC 參照是否有效。
5. 寫入世界任務池，玩家接受時移轉到角色任務清單。

## 5. 戰鬥

- 即時 2D：方向鍵／WASD 移動、單鍵普通攻擊、簡易技能或道具快捷鍵。
- MVP 先做 2 種敵人（近戰追擊、保持距離），3 種受擊／勝利回饋。
- 命中結果由規則層判定；渲染、動畫和音效不能直接決定傷害數值。
- 戰鬥脫離、死亡、重生、物品掉落與任務計數都需有明確規則。
- 預設死亡回城且損失部分金錢，不永久刪除角色；平衡數值在測試後調整。

## 6. 時間與 NPC

- MVP 的時間只在遊戲啟動且未暫停時推進；切換分頁可暫停，不做離線追趕。
- 建議原型速率：**現實 20 分鐘 = 遊戲 1 天**（可調參數，不是固定承諾）。
- 酒館 NPC、商人、委託人有最小狀態模型：所在地、互動選項、聲望門檻。
- 角色行為能增加／減少地區聲望；至少一個 NPC 的台詞或委託受聲望門檻影響。
- NPC 模擬先採「附近區域活躍、遠處事件排程」而不是每隻 NPC 都跑逐幀 AI。

## 7. 物品與經濟

- 素材、消耗品、裝備、任務物品四類；每個物品具有 itemDefId 與唯一實例 ID（必要時）。
- 商店價格以靜態基價加上少數聲望或事件修正，不急著做整個世界動態供需。
- 掉落表與任務報酬可由資料檔調整；禁止程式碼內散落大量魔法數字。

## 8. UI／UX

- 主畫面：中央遊戲世界；左上角色生命與狀態；右上小地圖／當前地點；底部快捷列。
- 城鎮互動：酒館委託、對話與商店使用 HTML DOM 疊層；避免小字全部畫進 Canvas。
- 任務追蹤顯示當前目標、進度與地點；不強制玩家只能追一個。
- 桌面鍵盤為優先操作；觸控採虛擬方向鈕／點擊移動等模式擇一測試。
- 繁體中文優先；支援減少動畫、可調整音量、避免純色辨識狀態。

## 9. 後續擴展

P1：善惡／陣營、NPC 同伴、關係、製作、事件鏈。  
P2：壽命、婚姻／家庭、後代（需要完整規則及資料轉移設計）。  
P3：創作任務、社群內容審核、共同世界／多人同步。

## 10. 重要平衡風險

- 隨機地圖的可達性與任務死鎖。
- 重複任務感與自動生成文本品質。
- 開放式成長被重複操作濫用。
- 背包／物品去重與重載時的複製漏洞。
- 單人與未來多人規則不同步。

**原則：先讓十餘分鐘內有明確的完整冒險循環，再擴充自由度。**
